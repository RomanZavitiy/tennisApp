# MatchFinder Kraków

Веб-застосунок для пошуку тенісного партнера (спарингу) у Кракові: карта кортів,
дошка пропозицій "шукаю спаринг" і профіль гравця з рейтингом, що росте з реальних
матчів. Натхненний окремими фічами twojtenis.pl, але головний фокус — саме
matchFinder, не бронювання кортів.

Правила роботи для AI-агентів і людини-рев'юера — у [AGENTS.md](./AGENTS.md).

## Технологічний стек — що є що

Короткий словник для кожної технології зі стеку: що це і навіщо воно тут. Якщо
бачиш незнайоме слово в коді чи PR — дивись сюди.

| Технологія | Що це робить |
|---|---|
| **Next.js 16** (App Router) | Фреймворк поверх React. Дає і фронтенд (сторінки), і бекенд (API-роути/server actions) в одному проєкті — окремий Express-сервер не потрібен. |
| **TypeScript** | JavaScript з типами. Помилки (переплутане поле, не той тип) видно ще до запуску коду, а не в проді. |
| **Supabase** | Керована база даних (Postgres) + автентифікація користувачів + сховище файлів (фото) + realtime-підписки — все в одному сервісі замість чотирьох окремих. |
| **Prisma** | ORM: шар між кодом і базою даних. Замість сирого SQL пишеш типізовані виклики (`prisma.user.findMany(...)`), і TypeScript одразу підкаже помилку. Також сам генерує й накатує міграції (зміни структури таблиць). |
| **Tailwind CSS** | Стилізація прямо в розмітці маленькими класами (`class="flex p-4"`) замість окремих `.css`-файлів із селекторами. |
| **shadcn/ui** | Не пакет-"чорна скринька", а готові шматки коду компонентів (кнопки, форми, модалки) на базі Tailwind, які копіюються прямо в проєкт — код одразу видно і можна редагувати. |
| **react-leaflet + OpenStreetMap** | react-leaflet — React-обгортка над Leaflet (бібліотека інтерактивних карт). OpenStreetMap — безкоштовне джерело картографічних даних, без ключа й лімітів Google Maps. |
| **React Hook Form** | Керує станом форми (поля, помилки, відправка) без зайвих перерендерів. |
| **Zod** | Опис схеми даних ("email — рядок з @, вік — число ≥18"), яка перевіряє дані і на клієнті (форма), і на сервері (перед записом у БД) — одна схема, не дублюємо логіку. |
| **Resend** | Сервіс відправки email (підтвердження реєстрації, сповіщення про нову пропозицію спарингу) через простий API. |
| **Vercel** | Хостинг від творців Next.js. Пуш у GitHub → автоматичний білд і деплой, прев'ю-посилання на кожен PR. |
| **GitHub Actions** | CI: скрипт, що на кожен push/PR автоматично прогонить лінтер, typecheck і тести — той самий зелений/червоний прапорець у GitHub. |
| **Vitest** | Юніт-тести: автоматична перевірка, що окрема функція (напр. розрахунок ELO) повертає правильний результат. |
| **Playwright** | End-to-end тести: відкриває справжній браузер і "клікає" по застосунку як користувач — перевіряє весь флоу (зареєструватись → створити оферту → приєднатись). |
| **pnpm** | Менеджер пакетів, як npm/yarn, але швидший і економніший на диску. |
