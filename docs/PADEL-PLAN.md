# План: падел у SpinBuddy (слайси PD1–PD5)

Дата: 2026-11-16. Підстава — [HIPADEL-ANALYSIS.md](./HIPADEL-ANALYSIS.md). Правила роботи —
[AGENTS.md](../AGENTS.md). Одна сесія = один слайс = один бранч `feat/PD<n>-…` і один PR.

## Принципи

1. **Один застосунок, два спорти.** Акаунт, чат, сповіщення, надійність, модерація — спільні.
   Від спорту залежать: оферти, клуби, рівень гравця, рейтинг.
2. **Активний спорт — cookie `SB_SPORT`**, як мова в `NEXT_LOCALE`: без сегмента в URL, типово
   теніс. Перемикач у шапці. Сторінка конкретної оферти чи клубу показує свій спорт незалежно від
   перемикача.
3. **Теніс не змінюється.** Усі нові колонки мають типове значення `TENNIS`; наявні рядки, тести
   й e2e лишаються чинними.
4. **Падел — завжди пара** (4 гравці). Рівень 1.0–7.0 з кроком 0.5, зберігається в тих самих
   колонках оферти `ntrp_min`/`ntrp_max` (назва історична; перейменування колонки — окреме
   рішення, зараз не потрібне).
5. Нічого з платежів, нативного застосунку, нових зовнішніх сервісів.

## PD3 — Найкраще з HiPadel (сесія 3)

- [x] PD3.1 **Тип матчу**: enum `MatchGender` (ANY / MEN / WOMEN / MIXED) в оферті, поле форми
  «Для кого», фільтр стрічки `?gender=`, позначка на картці й сторінці. MEN / WOMEN перевіряються
  при заявці, черзі очікування й інвайті; автор може створити лише гру своєї статі. MIXED —
  лише пара (CHECK), нікого не відсікає. Такі ігри не йдуть у push, кандидати, «Грати сьогодні» й
  push про «Шукаю гру» гравцям іншої статі. Для обох спортів.
- [x] PD3.2 **Приватний матч**: `SparringOffer.visibility` (PUBLIC / PRIVATE). Приватна не потрапляє
  в стрічку, лендинг, сторінку клубу та лічильник «шукають партнера», «Грати сьогодні», push і
  кандидати; сторінка відкривається за посиланням (noindex), заявки працюють як раніше.
- [x] PD3.3 **Інвайт-посилання**: токен на оферті (`invite_token`, унікальний, `null` — вимкнено);
  автор вмикає, копіює, замінює, вимикає. Хто відкрив поточне посилання і ввійшов — одразу отримує
  прийняте місце, доки є місця. Окремого ліміту використань немає: його замінює кількість місць.
  Рішення й доступ — `decisions.md`, 2026-11-17.
- [x] PD3.4 **Улюблені гравці**: таблиця `player_favorites` (до 20, приватна, не через блок), кнопка
  на профілі гравця, список у своєму профілі, «Запросити улюблених» на своїй відкритій грі (ті самі
  правила й ліміт, що й звичайний інвайт), push «улюблений гравець створив гру» в межах денного
  ліміту push і без дублю з push «нова гра для мого рівня».
- [x] PD3.5 **Фільтр за клубом** у стрічці (`?club=`), клуби активного спорту.

## PD4 — Результати й рейтинг падел (сесія 4)
