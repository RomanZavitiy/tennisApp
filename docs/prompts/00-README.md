# Промпти для розробки MatchFinder Kraków — 10 сесій

Кожен файл — це повний промпт для однієї сесії агента (Claude Code) у вашому репозиторії.
Сесії йдуть строго по порядку: кожна спирається на результат попередньої.

## Як користуватись

1. Покладіть цю папку в репозиторій як `docs/prompts/`, а новий план — як `docs/PLANNING.md`.
   Старий план агент сам збереже в архів у сесії 01.
2. Для кожної сесії відкрийте **нову** сесію Claude Code в корені репозиторію і напишіть:
   `Виконай docs/prompts/01-session-audit-and-offer.md`
   (або вставте вміст файлу повністю).
3. Дозвольте агенту редагувати файли й запускати команди в репо без підтвердження кожного кроку —
   інакше сесія займе в кілька разів довше.
4. Наприкінці сесії агент дає звіт і відкриває PR. Перевірте preview-деплой за пунктами звіту,
   змерджіть PR — і тільки тоді починайте наступну сесію.
5. Якщо сесія не встигла все — у `.agents/MEMORY.md` буде нотатка передачі. Відкрийте нову сесію
   з тим самим файлом промпту: агент продовжить із нотатки.

## Загальні правила, вшиті в кожен промпт

- Джерела правди: `AGENTS.md`, `docs/PLANNING.md`, `.agents/decisions.md`, `.agents/MEMORY.md`.
- Одна сесія = один слайс = одна гілка = один PR.
- Агент зупиняється лише в 4 випадках: новий зовнішній сервіс, міграція з видаленням чи
  перейменуванням даних, RLS-політика, що відкриває читання, потрібен секрет.
- Наприкінці сесії: чекбокси в `PLANNING.md` оновлені, нотатка передачі в `MEMORY.md`, звіт.
