# MEMORY.md — робочі нотатки агента

Журнал помилок агента за правилом «двох страйків» (AGENTS.md §10):

- **Перший страйк:** коли агент уперше робить певну помилку, він записує її сюди — що сталося,
  як це помітили, як правильно.
- **Другий страйк:** якщо та сама помилка повторюється, вона стає постійним правилом в
  `AGENTS.md`, а запис тут позначається «→ перенесено в AGENTS.md §N».

Так `AGENTS.md` не роздувається разовими нотатками: якщо щось не варто записати двічі, воно не
варте постійного правила. Людина цей файл рядок за рядком не рев'юїть. Архітектурні рішення сюди
не пишуться — для них `decisions.md`.

Формат запису: `- YYYY-MM-DD — що пішло не так → як правильно.`
